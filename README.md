# Avien Word UDF Eklentisi

Microsoft Word'e UYAP Doküman Editörü (`.udf`) desteği ekleyen eklenti.

## Ne yapar?

- **UDF Aç** — `.udf` dosyasını Word'de açar.
- **UDF Olarak Kaydet** — Word belgesini `.udf` biçiminde kaydeder.
- **Kaydet ve İmzala** — Belgeyi akıllı kart (e-imza) ile imzalayıp `.udf` kaydeder.

## Kurulum

1. [Releases](../../releases) bölümünden `AvienWordEklentisi-Kurulum.exe` dosyasını indirin.
2. Word kapalıyken çalıştırıp yönergeleri izleyin. Yönetici izni gerekmez; kurulum yalnızca o Windows kullanıcısı için yapılır.
3. Word'ü açın — Giriş sekmesinde **UYAP** grubu görünür.

### Gereksinimler

- Microsoft Word (masaüstü sürüm)
- Microsoft Visual Studio 2010 Tools for Office Runtime (VSTO Runtime)
- E-imza için: akıllı kart + AKİS kart sürücüsü

### İndirme / çalıştırma uyarısı

Dosya henüz kod imzalama sertifikasıyla imzalanmadığından Windows SmartScreen bir uyarı gösterebilir. Devam etmek için **Ek bilgi → Yine de çalıştır** deyin.
